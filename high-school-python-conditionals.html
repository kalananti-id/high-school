NEEDS (Kebutuhan)

"Survival Mode & Functionality"

  • 🏠
    Mutlak Diperlukan Tanpa ini, kita tidak bisa hidup atau bekerja.
  • ⚡
    Prioritas Tinggi Harus dipenuhi SEBELUM memikirkan hal lain.
Contoh: Makan, Tempat Tinggal, Internet (untuk sekolah).

WANTS (Keinginan)

"Comfort & Happiness"

  • 🍦
    Tambahan (Opsional) Membuat hidup lebih asik, tapi BUKAN syarat hidup.
  • 📉
    Prioritas Rendah Dipenuhi HANYA JIKA sisa sumber daya masih ada.
Contoh: Netflix Premium, Skin Game, Boba.

Plan B: else

Apa yang terjadi jika syarat TIDAK terpenuhi? Kita butuh jalan alternatif. else menangkap semua kondisi yang gagal di if.

if hujan_turun:
    buka_payung()
else:
    pakai_topi()

The Waterfall Effect 🌊

1. Cek IF Pertama
Jika True -> Stop disini!
⬇️ (Jika False)
2. Cek ELIF
Jika True -> Stop disini!
⬇️ (Jika False)
3. Masuk ELSE
Pilihan terakhir (Default)

⚠️ Warning: Urutan Itu Penting!

Python malas. Begitu dia nemu yang BENAR, dia langsung berhenti dan tidak mengecek bawahnya.

❌ Salah Urutan

nilai = 95
# Ini BUG! Python cek > 70 dulu
if nilai > 70:
    print("Lulus C") # <-- KEPILIH INI!
elif nilai > 90:
    print("Dapat A") # <-- Gak pernah dicek

✅ Benar (Spesifik ke Umum)

nilai = 95
# Cek yang paling susah dulu
if nilai > 90:
    print("Dapat A") # <-- YES!
elif nilai > 70:
    print("Lulus C")
