Data Transaksi dalam Aplikasi Keuangan 💳

Dalam aplikasi keuangan, aktivitas pengguna biasanya dicatat sebagai data transaksi. Contohnya adalah pemasukan dari gaji atau pengeluaran untuk makan dan tagihan.

transaksi = [200000, -50000, 150000, -20000]
Positif = pemasukan
Negatif = pengeluaran

Kenapa penting?

Data bisa disimpan banyak sekaligus
Data bisa diproses untuk mencari pola
Data bisa dianalisis untuk mengambil keputusan

Dari Data ke Analisis 🧠

1️⃣
List

Data transaksi disimpan dalam list.

[200000, -50000, 150000, -20000]
2️⃣
Transform

Ubah data menjadi bentuk baru.

[abs(x) for x in transaksi]
3️⃣
Filter

Ambil data tertentu saja.

[-50000, -20000]
4️⃣
Sort

Urutkan data untuk dibaca.

[-50000, -20000, 150000, 200000]
5️⃣
Insight

Tarik kesimpulan finansial.

Pengeluaran perlu diperhatikan.
Jadi fokus sesi ini bukan sekadar sintaks, tapi bagaimana sintaks membantu kita membaca data dengan lebih cepat.

List Comprehension ⚡

List Comprehension adalah cara ringkas untuk membuat list baru dari data yang sudah ada.

[ekspresi for item in iterable]
Python akan menjalankan ekspresi untuk setiap item di dalam list.

Contoh

Menambah komisi harga aset
Menghitung diskon semua barang
Membuat data baru dari data lama

List Comprehension dengan Kondisi 🔍

Memfilter data

transaksi = [200000, 800000, 1500000, 300000] transaksi_besar = [t for t in transaksi if t > 500000]
Hasilnya hanya mengambil transaksi di atas Rp500.000.

Memberi label

label = ["Tinggi" if t > 1000000 else "Normal" for t in transaksi]
Kita bisa memakai if-else untuk mengubah nilai berdasarkan kondisi.

Fungsi Lambda 🧩

Lambda adalah fungsi kecil tanpa nama. Cocok digunakan saat kita butuh fungsi sederhana dalam waktu singkat.

def kali_dua(x): return x * 2 # versi singkat lambda x: x * 2

Biasanya dipakai bersama

map() → mengubah data
filter() → menyaring data
sorted() → mengurutkan data

map(), filter(), dan sorted() 🛠️

🔄
map()

Menerapkan fungsi pada setiap item.

🧲
filter()

Mengambil data yang memenuhi kondisi.

📈
sorted()

Mengurutkan data agar lebih mudah dibaca.

Dalam analisis keuangan, tiga tools ini sangat berguna untuk membaca pola transaksi dengan cepat.
