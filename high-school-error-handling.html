Senjata Kita: Try-Except 🛡️

Jangan biarkan program crash! Tangkap errornya.

try:
  # Kode berbahaya di sini
  umur = int(input())

except ValueError:
  # Penyelamat!
  print("Harus angka dong!")
1. TRY

"Coba jalankan kode ini..."

2. ERROR?

Jika ada error, STOP proses di blok Try, langsung lompat ke Except.

3. EXCEPT

"Tangkap errornya, dan jalankan rencana cadangan". Program SELAMAT!

Menangkap Pesan Rahasia (as e) 🕵️

Kadang kita ingin tahu kenapa error itu terjadi tanpa mematikan program.

except ValueError as e:
  print(f"Error: {e}")

Variable e berisi pesan error asli dari Python. Berguna untuk debugging atau memberi info detail ke user.

Formasi Lengkap: Try-Except-Else-Finally 🤖

1. TRY

Lakukan ini.

2. EXCEPT

Jalan jika GAGAL.

3. ELSE

Jalan jika SUKSES (tidak error).

4. FINALLY

SELALU jalan (Wajib). Biasanya untuk bersih-bersih memory.
