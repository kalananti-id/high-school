if not found:
    print("Student not found.")

    Coding untuk membaca data

    Kadang data mentah sulit dipahami kalau masih acak. Dengan program, kita bisa mengolah data agar lebih mudah dibaca.

    Dari data ke insight

    • Data siswa bisa diurutkan berdasarkan skor.
    • Ranking membantu kita melihat siapa yang berada di posisi atas.
    • Kategori membantu memberi rekomendasi tindak lanjut.
    • Search membantu menemukan data siswa tertentu dengan cepat.

    Jadi, kamu tidak hanya menulis kode. Kamu sedang membuat alat kecil untuk membantu membaca informasi.

    Cara membaca kode data

    Saat melihat kode yang berisi banyak data, jangan langsung panik. Baca strukturnya pelan-pelan.

    Strategi membaca kode

    • List biasanya ditandai dengan tanda kurung siku [].
    • Dictionary biasanya ditandai dengan kurung kurawal {}.
    • Key adalah nama data, seperti "name" atau "score".
    • Value adalah isi datanya, seperti "Alya" atau 82.

    Mindset saat coding

    • Data apa yang disimpan?
    • Bagian mana yang menjadi dasar sorting?
    • Output apa yang ingin ditampilkan?

    Mulai dari data sederhana

    Setiap program pengolahan data membutuhkan data awal. Di Student Opportunity Matcher, kita mulai dari dua data sederhana: nama siswa dan skor siswa.

    Contoh data satu siswa

    {"name": "Alya", "score": 82}

    Kenapa pakai name dan score?

    • name membantu kita mengenali siswa.
    • score menjadi dasar untuk mengurutkan data.
    • Dengan dua data ini, kita sudah bisa membuat ranking sederhana.

    Membaca struktur data

    Struktur data ini terlihat panjang, tapi sebenarnya polanya berulang.

    Cara membacanya

    • students adalah list.
    • Di dalam list, ada beberapa dictionary.
    • Setiap dictionary mewakili satu siswa.
    • Setiap siswa punya name dan score.

    Contoh satu item

    {"name": "Citra", "score": 91}

    Artinya: nama siswa adalah Citra, dan skornya 91.

    Apa itu sorting?

    Sorting adalah proses mengurutkan data berdasarkan aturan tertentu. Dalam proyek ini, aturan sorting-nya adalah skor siswa.

    Yang perlu dipahami

    • Data awal bisa acak.
    • Program mengambil skor dari setiap siswa.
    • Skor tertinggi akan ditempatkan di atas.
    • Hasil akhirnya menjadi ranking yang lebih mudah dibaca.

    Setelah data terurut, kita bisa lebih mudah membuat rekomendasi atau mengambil beberapa siswa teratas.

    Mainkan skornya

    Sebelum masuk ke Python, kita coba dulu hubungan antara skor dan ranking secara visual. Gunakan slider untuk melihat bagaimana perubahan skor bisa memengaruhi urutan siswa.

    Yang perlu kamu amati

    • Kalau skor Bima naik, apakah posisinya berubah?
    • Siapa yang berada di ranking pertama?
    • Apa yang terjadi kalau dua siswa punya skor yang mirip?
    • Kenapa sorting membantu kita membaca data lebih cepat?

    Cara eksplorasi

    Mulai dari skor default, lalu ubah satu skor saja. Bandingkan ranking sebelum dan sesudah. Setelah kamu paham polanya, kita akan menerjemahkan proses yang sama ke Python.

    Dari skor menjadi kategori

    Sorting membantu kita mengurutkan siswa. Conditional logic membantu kita memberi kategori berdasarkan skor.

    Cara berpikirnya

    • Jika skor tinggi, siswa bisa masuk kategori Competition Ready.
    • Jika skor cukup, siswa bisa masuk kategori Mentoring Candidate.
    • Jika skor masih rendah, siswa bisa masuk kategori Needs Support.

    Contoh logic kecil

    if score >= 85:
    category = "Competition Ready"
elif score >= 70:
    category = "Mentoring Candidate"
else:
    category = "Needs Support"

    Saatnya eksperimen dengan Python

    Di slide sebelumnya, kamu melihat ranking berubah secara visual. Sekarang, kita menggunakan Python untuk melakukan hal yang sama.

    Yang perlu dicoba

    • Ubah skor Bima menjadi 95. Apa yang terjadi?
    • Ubah skor Darren menjadi 85. Apakah posisinya naik?
    • Tambahkan satu siswa baru ke dalam data.

    Bagian kode paling penting

    sorted_students = sorted(students, key=lambda student: student["score"], reverse=True)

    Baris ini mengurutkan siswa berdasarkan skor dari tertinggi ke terendah.

    Kenapa perlu testing?

    Output pertama yang muncul belum cukup untuk membuktikan bahwa program sudah benar. Kita perlu mencoba beberapa perubahan data.

    Checklist testing

    • Apakah ranking berubah saat skor berubah?
    • Apakah siswa dengan skor tertinggi muncul di atas?
    • Apakah program tetap berjalan saat data baru ditambahkan?
    • Apakah output mudah dibaca?

    Kalau hasilnya error?

    • Cek koma antar dictionary.
    • Cek tanda kurung [] dan {}.
    • Cek nama key: harus sama, misalnya "score".
    • Cek indentation pada loop.

    Mencari data tertentu

    Student Search membuat program lebih interaktif. User bisa mencari siswa tertentu tanpa membaca seluruh ranking.

    Bagian penting

    • search_name menyimpan nama yang ingin dicari.
    • found membantu mengecek apakah siswa ditemukan.
    • lower() membuat pencarian tidak sensitif huruf besar dan kecil.
    • if not found menampilkan pesan jika siswa tidak ada.

    Challenge kecil

    Ganti search_name menjadi nama lain. Apa yang terjadi jika nama tersebut tidak ada di data?

    Mengambil data teratas

    Setelah data sudah diurutkan, kita bisa mengambil tiga data pertama sebagai Top 3.

    Bagian penting

    • sorted_students sudah berisi data yang terurut.
    • [:3] mengambil tiga data pertama dari list.
    • Loop digunakan untuk menampilkan setiap siswa di Top 3.

    Contoh output

    === Top 3 Recommended Students ===
Citra - 91 - Recommended for advanced opportunity
Eka - 88 - Recommended for advanced opportunity
Alya - 82 - Recommended for advanced opportunity
