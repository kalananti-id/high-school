Pembuka: Kenapa Input Harus Dijaga? 🤔

Dalam aplikasi financial literacy, data seperti jumlah uang, kata sandi, dan deskripsi transaksi adalah data penting. Kalau input salah, hasil perhitungan bisa ikut salah.

Input kosong ❌
Input negatif ❌
Format salah ❌
Karakter aneh / berbahaya ❌
Aplikasi yang aman tidak langsung percaya pada semua input pengguna.

Tujuan pembelajaran ✅

Membuat input validation untuk keamanan data
Mencegah input kosong, negatif, atau salah format
Memahami pentingnya sanitasi input
Memperbaiki bug akibat input tidak valid

Apa yang salah?

  • Nilai transfer negatif seharusnya ditolak.
  • Tanpa validasi, saldo justru bisa bertambah.
  • Ini contoh bug yang muncul karena aplikasi terlalu percaya pada input pengguna.
Karena itu, sebelum data diproses, kita harus mengecek apakah input valid dan aman.

Dua Pilar Keamanan Input 🛡️

✅
Data Validation

Memastikan data yang dimasukkan sesuai dengan aturan yang ditetapkan, misalnya harus berupa angka, tidak negatif, atau harus punya format tertentu.

🧹
Input Sanitization

Membersihkan input dari karakter yang mengganggu atau berbahaya sebelum data dipakai lebih lanjut di aplikasi.

Validation memeriksa apakah data sesuai aturan. Sanitization membersihkan data agar lebih aman dan rapi.

Jenis-Jenis Validasi Data 🔍

🔢
Validasi Tipe

Memastikan data punya tipe yang benar, misalnya int, float, atau str.

📏
Validasi Jangkauan

Memastikan nilai masuk akal, misalnya pemasukan > 0 atau persentase 0–100.

🧩
Validasi Format

Memastikan data mengikuti pola tertentu, misalnya email, nomor HP, atau password.

Contoh Validasi Format 📋

Sanitasi Input: Membersihkan Data 🧽

Stripping

Menghapus spasi ekstra di awal atau akhir input agar data lebih konsisten.

nama = input("Nama: ").strip()
Cocok untuk membersihkan input yang tidak sengaja berisi spasi.

Escaping

Mengubah karakter berbahaya menjadi representasi aman agar hanya dibaca sebagai teks.

<script> menjadi &lt;script&gt;
Ini membantu mencegah karakter tertentu diproses sebagai kode.

Apa yang Dilakukan Kode Tadi? 🧠

1️⃣
Sanitasi

`.strip()` membersihkan spasi yang tidak perlu di awal dan akhir input.

2️⃣
Validasi Tipe

`try-except ValueError` menolak input huruf atau format angka yang salah.

3️⃣
Validasi Jangkauan

`if saldo < 0` menolak angka negatif yang tidak logis.

Regex untuk Validasi Format 🔠

Apa itu regex?

Regex atau regular expression adalah pola yang dipakai untuk memeriksa apakah sebuah teks mengikuti format tertentu.

^\d{5}$
^ = awal string
\d = digit angka
{5} = tepat 5 digit
$ = akhir string

Aturan proyek hari ini

Kode pos Indonesia harus tepat 5 digit
Tidak boleh ada huruf
Tidak boleh kurang atau lebih dari 5 digit

Latihan Analisis: Valid atau Tidak? ✅❌

Contoh input saldo

" 300000 " → perlu strip(), lalu valid
"-5000" → angka, tapi tidak logis
"abc" → bukan angka

Contoh input kode pos

40123 → valid
4012A → tidak valid
1234 → tidak valid

Kapan Pakai Apa? 🧭

🧹
.strip()

Untuk membersihkan spasi ekstra dari input teks.

⚠️
try-except

Untuk mengecek apakah input bisa diubah ke angka tanpa error.

🔤
re / regex

Untuk memeriksa pola format tertentu seperti kode pos, email, atau password.
