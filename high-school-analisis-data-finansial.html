Slicing: Mengambil Sebagian Data ✂️

Kadang kita tidak perlu melihat semua data. Kita hanya ingin melihat sebagian data.

1
start
Indeks awal (inklusif)
2
end
Indeks akhir (eksklusif)
3
step
Loncat antar elemen
Sintaks:
list[start:end:step]

Contoh:
transaksi = [12000, 15000, 8000, 10000, 5000]
print(transaksi[:3])
print(transaksi[::2])

Output:
[12000, 15000, 8000]
[12000, 8000, 5000]

Looping: Membaca Data Satu per Satu 🔁

Kenapa perlu loop?

Kalau kita punya banyak data, akan repot jika menghitung atau menampilkan satu per satu secara manual.

Dengan for loop, Python akan membaca setiap item dalam list secara berurutan.

Contoh sederhana

pengeluaran = [12000, 15000, 8000]

for harga in pengeluaran:
  print(harga)

Hasilnya: Python akan mencetak 12000, lalu 15000, lalu 8000.

Mengurutkan Data dengan Sorting 📈

Kenapa data perlu diurutkan?

  • Supaya gampang melihat pengeluaran paling kecil.
  • Supaya gampang mengambil data termahal.
  • Supaya laporan analisis jadi lebih rapi.
daftar_harga = [15000, 8000, 12000, 20000, 5000]
daftar_harga.sort()
print("Data setelah diurutkan:", daftar_harga)

Setelah diurutkan

Nilai paling kecil ada di awal list, dan nilai paling besar ada di akhir list.

[5000, 8000, 12000, 15000, 20000]
3 harga termahal = daftar_harga[-3:]

Contoh materi di modul menggunakan 3 harga termahal. Nanti di proyek kita naikkan menjadi 5 harga termahal.

Menghitung Rata-rata 📉

Rumus

rata_rata = total / jumlah_data

Setelah total diketahui, kita tinggal membagi dengan banyaknya data.

Contoh

rata_rata = total / len(pengeluaran)

Dari rata-rata, kita bisa melihat apakah pengeluaran kita cenderung besar atau masih terkendali.

Enumerate: Membuat Laporan Lebih Rapi 🧾

Kenapa pakai enumerate()?

Karena kadang kita ingin menampilkan nomor urut sekaligus isi datanya.

Cocok untuk:
  • daftar pengeluaran
  • daftar transaksi
  • laporan analisis

Contoh

pengeluaran = ["Makanan", "Transportasi", "Pakaian"]

for i, item in enumerate(pengeluaran):
  print(f"{i + 1}. {item}")
