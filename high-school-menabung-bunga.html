Uang Bekerja Untuk Kita? 🤔

Saat kamu menabung di bank, bank "meminjam" uangmu untuk diputar kembali. Sebagai imbalannya, bank memberimu Bunga.

Rumus Bunga Tunggal (Simple Interest):

Bunga = Pokok × Suku Bunga × Waktu Total Akhir = Pokok × (1 + Suku Bunga × Waktu)
*Waktu dalam tahun
🏦

5.3.1 Struktur Fungsi (Revisited) 🔍

Definisi:

def sapa_pelanggan(nama):
    print(f"Halo, {nama}!")
  • • nama (di dalam kurung def) adalah PARAMETER.
  • • Variabel penampung nilai yang akan diproses.

Pemanggilan:

sapa_pelanggan("Andi")
  • • "Andi" (data asli) adalah ARGUMEN.
  • • Data nyata yang dikirim ke fungsi.

Jenis Argumen 🎯

Saat memanggil fungsi, cara kita memberikan data itu penting.

1

Argumen Posisi (Default)

Nilai diberikan sesuai urutan parameter.

def tabungan(nama, jumlah): ...

tabungan("Budi", 50000) ✅
tabungan(50000, "Budi") ❌ Error/Aneh
2

Argumen Kata Kunci

Nilai diberikan dengan menyebut nama. Urutan tidak penting!

tabungan(jumlah=75000, nama="Citra") ✅
# Hasil tetap benar walau dibalik

Nilai Default (Bantuan Otomatis) 🤖

Kamu bisa memberikan nilai awal pada parameter. Jika user lupa/malas mengisi argumen, nilai default ini yang dipakai.

def buat_akun(nama, saldo_awal=0):
    print(f"{nama} punya {saldo_awal}")
Skenario 1: User hanya kasih nama.
buat_akun("Dina")
👉 Saldo otomatis 0.
Skenario 2: User kasih nama & saldo.
buat_akun("Eko", 50000)
👉 Saldo jadi 50000 (0 tertimpa).

Print() vs Return 🥊

Ini kesalahan paling umum pemula! Keduanya "mengeluarkan sesuatu", tapi tujuannya beda total.

Fitur print() 📢 return 📦
Tujuan Hanya MENAMPILKAN info ke layar (konsol). MENGIRIMKAN nilai balik ke kode pemanggil.
Data Output Tidak bisa disimpan dalam variabel. (Nilainya None) Bisa disimpan di variabel untuk hitungan lanjut.
Kontrol Fungsi jalan terus sampai habis. Fungsi BERHENTI (Kill) seketika itu juga.
