Warm-up: 100 Transaksi = 100 Variabel? 😵‍💫

Bayangin kamu nyatet pengeluaran harian. Kalau pakai variabel, jadinya:

transaksi1 = -15000
transaksi2 = -25000
transaksi3 = 50000
... sampai transaksi100 😭
Masalahnya: ribet, susah dijumlah, susah di-update, dan gampang salah.

Solusi hari ini ✅

Pakai List: banyak data transaksi disimpan dalam satu variabel.

📦
ledger = [ ... ]
Urutan transaksi tetap rapi dan mudah diolah.
Interaksi cepat: “Kalau kamu punya 100 transaksi, kamu lebih pilih 100 variabel atau 1 list?”

Apa itu List? 🧠

List adalah kumpulan data yang terurut dan bisa diubah (mutable).

🧭
Terurut
Elemen disimpan sesuai urutan masuknya.
🧱
Mutable
Bisa ditambah, dihapus, atau diubah.
🧩
Bisa campur tipe
Angka, teks, boolean, dsb bisa satu list.
Contoh (List transaksi):
ledger = [500000, -200000, -50000]

Contoh (List campuran detail):
detail = ["Gaji Bulanan", 15000000, "2024-09-01", True]

List kosong:
ledger = []

Mengakses Data dengan Indeks 🔍

Aturan penting

  • Indeks dimulai dari 0.
  • Indeks -1 artinya elemen terakhir.
  • Indeks membantu kita ambil item tertentu tanpa mengubah list.
ledger = [500000, -200000, -50000]

ledger[0] → 500000
ledger[1] → -200000
ledger[-1] → -50000

Menambah & Menghapus Transaksi ➕➖

.append(x)

Menambah item ke akhir list.

ledger = []
ledger.append(500000)
ledger.append(-200000)
print(ledger) # [500000, -200000]

.pop()

Menghapus item terakhir (cocok untuk fitur Undo).

ledger = [500000, -200000]
ledger.pop()
print(ledger) # [500000]
Interaksi cepat: “Kalau kamu salah input transaksi terakhir, fitur apa yang kamu butuhkan?” → Undo (pop)

Tugas (20 menit)

Ringkasan Saldo: sum() atau loop? 🧮

Cara 1: sum()

Paling cepat kalau datanya angka semua.

saldo_akhir = sum(ledger)

Cara 2: Loop (bonus)

Bagus untuk latihan logika.

saldo = 0
for t in ledger:
  saldo += t
