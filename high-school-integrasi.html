Hari ini kita belajar menggabungkan beberapa konsep Python menjadi satu proses analisis data finansial yang lebih nyata.

Function Loop Conditional Dictionary

Review: Kenapa Harus Digabung? 🤔

Dalam aplikasi nyata, satu konsep saja biasanya tidak cukup. Untuk memproses transaksi keuangan, program perlu membaca data, menghitung hasil, lalu menampilkan ringkasan.

Function → mengatur logika
Loop → membaca data satu per satu
Dictionary → menyimpan hasil analisis
Semakin besar data, semakin penting struktur kode yang rapi.

Tujuan pembelajaran ✅

Memahami peran function, loop, dan dictionary
Membuat fungsi ringkasan keuangan
Membaca daftar transaksi dengan loop
Menampilkan hasil analisis dengan label yang jelas

6.6.1 Menggabungkan Konsep dalam Pemrosesan Data 🧠

🛠️
Function

Membungkus logika agar kode lebih rapi dan bisa dipakai lagi.

🔁
Loop

Membaca setiap transaksi satu per satu dari daftar data.

📘
Dictionary

Menyimpan hasil analisis dengan pasangan key dan value.

Tiga konsep ini sering muncul bersamaan dalam aplikasi keuangan, terutama saat membuat laporan atau ringkasan transaksi.

Contoh Data Transaksi 💸

Setiap transaksi memiliki dua informasi utama: jenis transaksi dan jumlah uang. Data ini bisa disimpan dalam bentuk list of tuples.

transaksi_bulan_ini = [ ("Pemasukan", 5000000), ("Pengeluaran", 1200000), ("Pemasukan", 2000000), ("Pengeluaran", 550000) ]

Apa yang bisa dihitung?

Total pemasukan
Total pengeluaran
Saldo akhir

6.6.2 Membuat Fungsi Pemrosesan Data Keuangan ⚙️

Langkah kerja fungsi

  1. Membaca setiap transaksi
  2. Memisahkan pemasukan dan pengeluaran
  3. Menjumlahkan total pemasukan
  4. Menjumlahkan total pengeluaran
  5. Menghitung saldo akhir

Output yang diinginkan

• Saldo Awal
• Total Pemasukan
• Total Pengeluaran
• Saldo Akhir

6.6.3 Menampilkan Hasil Analisis 📊

Setelah fungsi dipanggil, hasil ringkasan akan tersimpan dalam dictionary. Kita bisa menampilkannya dengan loop agar setiap bagian punya label yang jelas.

for key, value in ringkasan.items(): print(f"{key}: Rp {value:,}")

Contoh hasil

Saldo Awal: Rp 10.000.000
Total Pemasukan: Rp 7.000.000
Total Pengeluaran: Rp 2.050.000
Saldo Akhir: Rp 14.950.000

Kenapa perlu validasi?
