Nabung Receh 🐖

"SELAMA celengan belum penuh, terus masukkan koin setiap hari."

Kondisi berhenti: Celengan Penuh.

Di Python, kita punya 2 cara untuk melakukan pengulangan ini.

1. While Loop

"Lakukan SELAMA target belum tercapai"

while uang < target_hp_baru:
    menabung(5000)
    print("Semangat nabung!")
Menabung...
⚠️ Penting: Pastikan saldo terus bertambah! Jika saldo tidak pernah berubah, kita akan menabung selamanya (Infinite Loop).

Demo: Tabungan Target 💰

Nabung terus sampai target tercapai.

⚠️ Infinite Loop

Jika kondisi selalu True, program akan berputar selamanya sampai komputer hang/crash.

while True:
    print("Aku tidak bisa berhenti!")
    # Lupa update kondisi :(

Loop Control: Break vs Continue

BREAK

Berhenti Paksa!

Keluar dari loop seketika itu juga, tidak peduli kondisi while/for.

if uang_habis:
    break 🛑
CONTINUE

Skip Putaran

Lewati sisa kode di bawah, langsung lompat ke putaran berikutnya.

if tanggal_merah:
    continue ⏭️

2. For Loop

"Ulangi sejumlah item yang ada"

for hari in ["Senin", "Selasa", "Rabu"]:
    sekolah(hari)
Senin
Selasa
Rabu

Magic Tool: range()

range(5)
生成 0, 1, 2, 3, 4 (Stop di N-1)
range(1, 6)
Start 1, Stop 6 → 1, 2, 3, 4, 5
range(0, 10, 2)
Step 2 → 0, 2, 4, 6, 8

1
2
3
4

Ingat! Range berhenti SEBELUM angka stop.
