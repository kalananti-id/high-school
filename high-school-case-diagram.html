Apa itu Use Case Diagram? 🧠

Use Case Diagram (UCD) adalah alat visual untuk menggambarkan fungsi sistem, interaksi antara pengguna dan sistem, serta batas sistem.

Pertanyaan utamanya: “Apa yang dapat dilakukan pengguna dengan sistem ini?”
Kegunaan UCD
  1. 1. Menggambarkan fungsionalitas sistem
  2. 2. Menunjukkan interaksi pengguna
  3. 3. Menentukan batas sistem

Komponen Use Case Diagram 🔍

🧍
Actor

Pihak luar yang berinteraksi dengan sistem. Contoh: Pengguna, Administrator.

⭕
Use Case

Fungsi atau tindakan yang dilakukan sistem sebagai respons interaksi aktor.

⬜
System Boundary

Batas sistem yang memuat seluruh use case di dalam aplikasi.

↔️
Relationship

Hubungan antara aktor dengan use case atau antar use case.

Program Flow: Alur Program 🔄

1️⃣
Sequential

Jalan lurus dari input ke proses lalu ke output.

2️⃣
Conditional

Program memilih jalur berdasarkan kondisi.

3️⃣
Iterative

Program mengulang proses dengan loop.

Setelah kita tahu fitur apa yang ada di aplikasi, kita perlu menentukan bagaimana alurnya dijalankan oleh kode.

Sequential Flow: Jalan Lurus ▶️

Instruksi dijalankan satu per satu dari atas ke bawah.
