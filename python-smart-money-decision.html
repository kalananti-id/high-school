Dari nominal ke persentase

Nominal uang bisa berbeda-beda, tapi persentase membantu kita membandingkan kondisi dengan lebih adil.

🛒

Expense Ratio

Berapa persen pemasukan yang digunakan untuk pengeluaran?

expense_ratio = expense / income
🏦

Saving Ratio

Berapa persen pemasukan yang berhasil ditabung?

saving_ratio = saving / income

Contoh

Jika income = 1000000, expense = 750000, dan saving = 150000:

  • Expense Ratio: 750000 / 1000000 = 0.75 = 75%
  • Saving Ratio: 150000 / 1000000 = 0.15 = 15%

Python menghitung rasio dalam bentuk desimal. Untuk menampilkan persen, kalikan dengan 100.

def check_money(income, expense, saving):
    expense_ratio = expense / income
    saving_ratio = saving / income

    if expense >= income:
        return "High Risk"
    elif expense_ratio > 0.8:
        return "Warning"
    elif saving_ratio >= 0.2 and expense_ratio <= 0.7:
        return "Healthy"
    elif saving_ratio >= 0.1:
        return "Moderate"
    else:
        return "Need Improvement"


print("Scenario 1 - Banyak jajan:", check_money(1000000, 900000, 50000))
print("Scenario 2 - Cukup seimbang:", check_money(1000000, 750000, 150000))
print("Scenario 3 - Lebih hemat:", check_money(1000000, 600000, 250000))

Banyak keputusan bisa dibuat lebih jelas kalau kita punya data. Dalam proyek ini, datanya sederhana: berapa pemasukanmu, berapa pengeluaranmu, dan berapa yang kamu tabung.

  • Kalau pengeluaran terlalu besar, program memberi status Warning.

Kenapa pakai persentase?

Dua orang bisa punya pemasukan yang berbeda, tapi kita tetap bisa membandingkan kebiasaan keuangan mereka dengan persentase.

Contoh perbandingan

  • User A punya income Rp1.000.000 dan expense Rp750.000 → pengeluaran 75%.
  • User B punya income Rp2.000.000 dan expense Rp1.500.000 → pengeluaran juga 75%.

Walaupun nominalnya berbeda, pola pengeluarannya sama: sama-sama memakai 75% dari pemasukan.

Menampilkan hasil sebagai persen

print("Expense Percentage:", round(expense_ratio * 100), "%")
              print("Saving Percentage:", round(saving_ratio * 100), "%")

Setelah program tahu persentasenya, kita bisa membuat aturan untuk menentukan status keuangan.

Decision table → if-elif-else

Decision table membantu kita menulis aturan sebelum masuk ke kode. Setelah aturannya jelas, kita bisa menerjemahkannya menjadi if, elif, dan else.

Cara Python membaca kondisi

  • Python mulai mengecek dari kondisi paling atas.
  • Jika satu kondisi benar, bagian itu dijalankan.
  • Kondisi berikutnya akan dilewati.
  • Kalau tidak ada kondisi yang benar, bagian else akan dijalankan.

Contoh potongan kode

if expense >= income:
                  status = "High Risk"
              elif expense_ratio > 0.8:
                  status = "Warning"
              elif saving_ratio >= 0.2 and expense_ratio <= 0.7:
                  status = "Healthy"

Karena itu, kita biasanya menaruh kondisi yang paling berisiko di bagian atas agar cepat terdeteksi.
